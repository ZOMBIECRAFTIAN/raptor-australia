# Behavior Videos — gui/static/behavior_videos/

Place one short video per species in this folder. The Species
Guide page detects them automatically and renders them next to
the AUSLAN sign animation in each card.

## Naming convention

Use the **exact species_key** as the filename, in MP4 (preferred),
WebM, or MOV — in this priority order:

```
aquila_audax.mp4              ← Wedge-tailed Eagle
falco_peregrinus.mp4          ← Peregrine Falcon
circus_assimilis.mp4          ← Spotted Harrier
tachyspiza_fasciata.mp4       ← Brown Goshawk
falco_cenchroides.mp4         ← Nankeen Kestrel
elanus_axillaris.mp4          ← Black-shouldered Kite
lophoictinia_isura.mp4        ← Square-tailed Kite
hieraaetus_morphnoides.mp4    ← Little Eagle
```

If the file is missing the card shows a polite "no video yet"
placeholder — nothing breaks.

## Recommended specs

| Parameter   | Recommendation                       |
|-------------|--------------------------------------|
| Codec       | H.264 (MP4) or VP9 (WebM)            |
| Resolution  | 720p (1280×720) — 4:3 aspect crop OK |
| Duration    | 5–15 seconds (looped behaviour clip) |
| File size   | ≤ 8 MB per file (keeps page snappy)  |
| Audio       | Strip the audio track (we mute it)   |
| Frame rate  | 24 or 30 fps                         |

A 10-second 720p MP4 at H.264 around 4–6 Mbps lands at ~5 MB.
That's the sweet spot.

To strip audio + recompress with `ffmpeg`:

```bash
ffmpeg -i input.mp4 -an -c:v libx264 -crf 23 -preset slow \
       -vf "scale=-2:720" aquila_audax.mp4
```

## Where to find Creative-Commons footage

### 1. Atlas of Living Australia — Multimedia search
- https://collections.ala.org.au/?q=multimedia:Video
- Filter by species name. Many records are CC-BY or CC-BY-NC.
- Click a record → check the licence tag → download original.

### 2. iNaturalist — observations with sound/video
- https://www.inaturalist.org → Explore → filter by *Sound/Media*
  and species.
- Download the observation media if licensed CC0/CC-BY/CC-BY-NC.

### 3. YouTube — Creative Commons filter
- Search for the species, then **Filters → Features → Creative
  Commons**.
- Use a downloader that respects the CC licence (e.g. `yt-dlp`)
  *only* for CC-licensed content.
- **Always** record the video URL and author in
  `attribution.csv` (see below) so you can credit them in your
  thesis or publication.

### 4. Macaulay Library (Cornell) — gated access
- https://www.macaulaylibrary.org has many high-quality clips
  but is **not** open licence by default. Use only for personal
  research with explicit written permission, **not** in a
  shipped / public repository.

### 5. Personal recordings
- Best option for licence cleanliness. If you film any of these
  species yourself, use those — credit yourself with CC-BY-4.0.

## Attribution

For every clip you place here, **add a row** to a sibling file
`attribution.csv` (create it on first use) with the columns:

```
filename,source_url,author,license,downloaded_on
aquila_audax.mp4,https://...,Jane Doe,CC-BY-4.0,2026-05-12
```

Keep that file alongside the videos so the licence chain is
traceable for your MPhil thesis appendix.

## What about the AUSLAN side?

The AUSLAN sign motion lives in
`gui/static/auslan_videos/<species_key>.svg` — those are the
provisional SMIL animations generated by
`notebooks/generate_auslan_svgs.py`. When you eventually replace
each `.svg` with a consented `.mp4` from the Deaf community
consultation (see `docs/auslan_consultation/`), the same
template logic detects the new extension and switches from
`<img>` to `<video>` automatically.
